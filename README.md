# Catholic Daily Devotional & Sanctuarium

A comprehensive Catholic daily devotional web application featuring daily Mass readings, saint of the day, Gospel commentary, Novena tracker, Church history timeline, prayers, and spiritual resources.

## Features
- Daily Mass Readings & Gospel Commentary
- Saint of the Day & Liturgical Calendar
- Interactive Novena Tracker & Prayer Treasury
- Church History Timeline & Educational Resources
- Catholic Links & Marian Apparitions Guide

## Tech Stack
- React & Vite
- TypeScript
- Tailwind CSS
- Lucide React Icons
